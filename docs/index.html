It collects the evidence.
You draw the conclusions.

A single PowerShell script that dumps an exhaustive snapshot of a Windows machine — hardware, storage, memory, network, startup, browsers, event logs — so someone holding only that log can work out why the PC is slow, freezing or unstable.

Download Invoke-WinDiag.ps1 View source

single file · ~190 KB · PowerShell 5.1 · Windows 10 / 11

Collect, don't conclude

This toolkit performs no analysis, assigns no severities, flags nothing as "critical", and offers no recommendations.

That's deliberate. A threshold baked in by the tool author is an opinion formed without knowing the machine, the workload, or the question being asked — and it biases whoever reads the output afterwards. So the log carries labelled facts plus neutral reference context, and never a verdict.

WHAT IT WRITES

Interrupts/sec: 412
CONTEXT: Windows default timer resolution is 15.6 ms, producing ~64 timer interrupts/sec at idle.

WHAT IT NEVER WRITES

Interrupts/sec: 412
⚠ CRITICAL — interrupt storm detected,
disable the offending driver

The output is meant to be handed to a technician or pasted into an AI for analysis. Both do better work when they're given facts rather than someone else's guess.

How to run it

1

Download the script

Save Invoke-WinDiag.ps1 anywhere — Desktop or Downloads is fine.

2

Open PowerShell and run it

Right-click Start → Terminal or Windows PowerShell. It asks for admin itself, so you don't need to launch it elevated. 

cd $env:USERPROFILE\Downloads
Set-ExecutionPolicy -Scope Process Bypass -Force
.\Invoke-WinDiag.ps1

The Set-ExecutionPolicy line applies to that window only and reverts when you close it — it doesn't change any machine setting. A UAC prompt will appear; approving it means storage health, kernel pool and driver data get collected instead of skipped.

3

Send the ZIP

It writes a WinDiag_<PC>_<date> folder and ZIP to the Desktop. Send that to whoever is diagnosing the machine — everything they need is inside it.

What it does to the machine

✓ Nothing

Read-only. No registry writes, no service changes, no cleanup, no "fixes". It reads state and writes a log.

✓ Survives a crash

Every line is flushed to disk as it's written. If the machine bluescreens mid-run, everything collected up to that moment is already saved.

✓ One failure doesn't stop it

Each collector is isolated with retries. A failure is recorded as FAILED in the log, so missing data stays distinguishable from a genuine empty result.

! The output is detailed

It contains machine names, user names, installed software, file paths and network configuration. Treat the package as sensitive and send it only to someone you trust.

What it collects

SYSTEM SUMMARY

Everything on the Settings → About page: device name, processor, RAM, graphics, storage, system type — plus the build-derived Windows generation, because the registry still says "Windows 10" on many Windows 11 machines.

STORAGE & FILESYSTEM

Decoded SMART attribute tables, NVMe PCIe link speed and width, MFT geometry and zone, USN journal, sector geometry and partition alignment, filter driver stack, TRIM, BitLocker, Storage Spaces, biggest folders and files.

CPU & MEMORY

Per-core utilisation, processor queue length, DPC and interrupt time, frequency vs base, power policy and throttle events, page faults, pool usage, handle and GDI counts per process, and a growth sample for leak evidence.

NETWORK

Adapters, Wi-Fi band and channel, 30-day per-profile data usage, DNS timing, proxy and PAC config, mapped drives, listening ports — and a live throughput measurement with latency distribution.

CONTENT FILTERING & TLS

Detects filtering software and, by comparing certificate issuers across unrelated sites, identifies TLS interception and names the party doing it. Built and verified against real filtered machines.

SOFTWARE & STARTUP

Every installed program, every executable on disk with its publisher, every driver file, scheduled tasks, services, Run keys, shell extensions, and browser extensions by name.

SEARCH HIJACK & PERSISTENCE

Default search engine and homepage per browser profile, browser policy keys, shortcut target arguments, force-installed extensions, protocol handlers — the places unwanted software changes things.

EVENTS & CRASHES

Errors grouped by frequency, application crashes and hangs, unexpected shutdowns and bugchecks, storage subsystem errors, GPU driver resets, and boot/logon performance events that name the process responsible.

Sysinternals tools (autorunsc, handle, sigcheck…) are used automatically if they're on PATH or sitting beside the script. If they're absent the run continues normally.

What you get back

WinDiag_LAPTOP-A1B2_2026-08-04_170000/
├── logs/
│   ├── Master.log        full execution log, ms timestamps
│   ├── Errors.log        collectors that FAILED
│   ├── Performance.log   per-collector execution time
│   └── Timeline.log
├── raw/          human-readable dumps, one per section
├── json/         structured data for programmatic analysis
├── csv/          tabular exports
├── eventlogs/    exported .evtx
├── counters/     performance counter capture
└── MANIFEST.json  written first, so the package is self-describing
                   even if the run is interrupted

Every log line follows one format:

[2026-08-04 17:04:22.117] [CHECK  ] [Get-DiskSmart] [+1.284s] C0042 SMART attributes

timestamp | severity | collector | elapsed | message
